5 分鐘上傳 GitHub Pages 步驟：

  1. 登入 GitHub 並建立一個公開儲存庫 (Public Repository)，名稱如 hk-driver-assistant。
  2. 下載上述 5 個檔案：index.html、manifest.json、sw.js、icon-192.png、icon-512.png。
  3. 將這 5 個檔案拖曳上傳至 GitHub Repository 根目錄並 Commit。
  4. 進入 Repo 的 Settings ➔ Pages，Source 選擇 Deploy from a branch，Branch 選擇 main / root，點擊 Save。
  5. 1-2 分鐘後即可開啟網址（如 https://.github.io/hk-driver-assistant/），手機點擊「加入主畫面」或用 PWABuilder 轉包 APK！
